# Word 论文样式与表格格式

本指南规定如何把期刊/学校格式要求落实为 Word 样式和表格格式。**格式值来自目标期刊官网规范、模板或作者提供的学位论文参考文件；本指南不提供覆盖目标规范的默认字号、字体或表格线型。**

## 先建格式映射

开始操作前，列出实际出现的内容类型与目标要求，例如：

| 内容类型 | Word 实现 | 需从规范/样例确认 |
|---|---|---|
| 论文题名/副题名 | 标题样式或专用段落样式 | 字体、字号、字重、对齐、间距 |
| 一级至多级标题 | 内置 Heading 1/2/3 等，或保留语义级别的自定义段落样式 | 编号层级、字体、缩进、段前段后、分页规则 |
| 摘要/关键词 | 标题和正文分别设置样式；中英文摘要可分别设样式 | 是否结构式、标题字样、字数范围、标签/分隔符 |
| 正文段落 | 正文段落样式 | 字体字号、行距、首行缩进、对齐、段间距 |
| 图题/表题 | Word Caption 样式或目标专用题注样式；自动编号由题注域生成 | 图/表标签、编号是否含章号、题注位置、标点和字体 |
| 表格 | Word 表格样式与必要的单元格/边框格式 | 三线表或其他边框、表头、字体字号、数值对齐、表注和跨页规则 |
| 参考文献 | 专用段落样式/目标模板样式 | 编号、悬挂缩进、行距、字体和条目格式 |

先抽查模板和正文现状，识别已有样式、直接格式和域。避免同一语义内容各自手工调格式，亦不要为了看上去统一而把不同内容类型套进同一个样式。

## 建立和应用 Word 样式

1. 以目标要求和样例为准，确定一份样式映射表；标题结构使用可导航的标题级别，确保级别关系正确。若期刊视觉格式与内置标题样式名称不同，可修改内置 Heading 样式或创建新的语义样式，但不能把所有标题做成无法识别层级的普通正文。
2. 优先修改文档中已有的正确样式；只有没有合适样式、且内容类型确实不同，才新建命名明确的样式。名称应能看出用途，例如 `中文摘要正文`、`英文摘要正文`、`图题`、`表题`、`表格正文`。
3. 样式属性依目标要求设置：字体（含中西文字体）、字号、加粗/斜体、对齐、行距、段前/段后、缩进、分页控制、编号/大纲级别等。不要从单篇参考稿的偶然格式推导成强制规范；多个样本呈现的惯例也须和官方要求区分记录。
4. 将样式应用于所有同类段落后，检查标题级别导航、目录收录、摘要正文与标签、图/表题注等。遇到域、交叉引用、题注或参考文献编号时，保护其 Word 域和编号，不要通过重建普通文本破坏自动更新功能。
5. 仅在当前文档范围内创建/修改样式，除非用户明确要求保存为可复用的 `.dotx` 模板或应用到其他文档；不要意外修改 Normal.dotm 或全局模板。

## 表格设置

- 先按目标期刊/学位论文样例确定表格结构和视觉规范，再设置表格样式或必要的局部边框。三线表、彩色底纹、竖线等均不能脱离目标规范擅自强制。
- 表格整体宽度、列宽、边距和对齐需适配页面及版心；核对表头、数据、单位、有效数字、注释和来源。不能为改善外观改动或推测表内数据。
- 表题和表格正文分开设置；表题用题注样式/自动题注编号，表注遵从模板要求。表格若跨页，设置并检查重复表头；避免用手动分页符切断需要自动重复表头的长表。
- 检查行是否被不当拆页、空白行/列、单元格溢出、字体异常、表格超出版心。渲染到 PDF 或打印布局检查至少一张普通表和每种复杂情况（跨页、宽表、合并单元格等）。
- Word 可直接套用表格样式，也可单独设置边框、底纹和单元格格式。只有实际创建了 Table Style 才报告为“新建表格样式”；直接调整表格边框或单元格属性应如实报告为局部格式设置。

## 交付时告知用户

在交付摘要中单列“样式变更”，准确列明：

- **新建样式：**名称、适用内容类型；若没有则写“无”。
- **修改的已有样式：**Word 中的样式名称、修改的大致属性；若没有则写“无”。
- **局部格式设置：**如单个表格边框、重复表头等非样式操作；若没有则写“无”。
- 若为复用而创建 `.dotx`，说明模板路径及适用范围。
