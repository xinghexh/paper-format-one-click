# 期刊样文统计与格式符合性

## 用户选择

目标期刊仿写/内容模仿任务中，七篇方向相关论文的研究与量化统计为强制步骤，不再询问是否跳过。纯格式整理且用户未要求内容仿写时，不触发七篇研究统计。用户没有给出期刊或参考论文时，先询问目标；在目标确定并收齐官网要求前，不进入仿写。

学位论文不是上述期刊样文统计选项的替代场景。作者需提供学校格式规范、模板或参考论文/文件，供学习和模仿；正式校规优先于单篇样例。缺少文件时，索要文件后再做格式模仿。

## 样本选择与统计口径

1. 确认目标期刊、文章类型/研究类型、学科主题和时间范围。优先使用近 3–5 年、同一文种且主题相近的已发表论文；若可获取样本很少，应如实缩小或放宽条件并说明。
2. 优先查期刊官网/出版商页面上的正式全文、HTML 或 PDF。记录样本标题、文种、发表年份和可访问来源；无法访问全文的文章不得用于统计表格、结论等全文结构指标。
3. 报告有效样本数 `n`、时间范围、来源以及统计口径。摘要、正文词数可用可复核的统一口径计算；中文可按字符数或分词数，英文可按词数。一个报告内保持同一口径，明确是否排除标题、图表、参考文献和补充材料。
4. 将观测事实、统计结果与风格建议区分开。样本规律只是编辑参考，不是期刊要求，不可覆盖官网规范。

## 仿写任务的七篇论文统计项目（强制）

逐篇记录参考文献总数、可核验的文内引文出现次数、参考文献出版年代分布、中文/外文比例、期刊论文/专著/标准等类型分布、与本稿主题的方向分布；报告统计口径、有效样本数及中位数/范围。引用条目分类按实际可确认信息，不能判定的单列未知。逐篇记录正文总字数与各可比章节字数；总结样本常用术语、章节结构、论证顺序和篇幅分布，并形成“样本观察—本稿处理”映射。逐篇完整解析参考文献列表，统计总量、出版年份（最近五年比例）、文献类型（期刊/会议/专著/标准/其他）、中外文语种比例及主题分布；报中位数和范围。本稿的可比章节篇幅和相关参考文献规模低于样本中位数 80% 时判未通过，除非正式篇幅上限/文种差异构成明确理由，须记录具体理由并采用同类型样文重新设基准。不能用“官网没有最低要求”掩盖样稿明显偏短或参考文献明显偏少；不能为达到数量而添加不相关、未核实来源。七篇是最低样本量，不等于机械凑数。

## 建议统计项目

| 维度 | 统计或观察内容 | 建议报告方式 |
|---|---|---|
| 摘要长度与占比 | 摘要字符/词数；相对正文（不含摘要、参考文献）的字数比例；不同样本的分布 | n、范围、中位数/均值；说明分母与算法。若版面/PDF无法精确计数，标为估算，不报虚假精确值 |
| 摘要结构 | 是否结构式摘要；背景、目的、方法、结果、结论的出现顺序；关键词数 | 报告各类型/要素出现频次及常见模式 |
| 摘要引用 | 是否出现文内引文、引用数量/出现率、位置 | 逐篇计数；不要仅凭几篇无引用摘要推断禁止引用 |
| 文内引用 | 作者—年份或顺序编码；作者导向与结论导向；单引、合并引文、同句引文密度 | 展示频次/比例和例子；引用风格以官网要求为准 |
| 图表 | 图、表数量与分布；题注位置；子图标识；正文中图表指代用语；表格是否需三线表/注释/单位 | 区分强制格式与样本习惯；报告数量分布或常见模式 |
| 结论组织 | 是否单列结论；使用编号小点（如（1）（2）（3））还是连续段落；是否含局限/展望 | 逐篇记录结构，汇总常见模式；不可将样本偏好误当强制规定 |
| 其他版式 | 标题层级、章节顺序、关键词、公式编号、补充材料等 | 仅统计与本任务直接相关的维度 |

摘要“占比”计算示例：

`摘要占全文正文比例 = 摘要字符数（或英文词数）÷ 正文字符数（或英文词数）× 100%`

同时报告摘要绝对长度，避免只报比例造成误读。对包含多个语言版本摘要的论文，应分别统计，不把中英文摘要重复合计。

## 强制要求符合性检查

样文统计前后都必须核对期刊官网或学校正式文件。把要求拆成原子检查项，至少涉及本次编辑范围内的：标题层级、摘要长度/结构、关键词、正文结构、引文体例、参考文献、表格、图及题注、公式、页码/页眉、补充文件和投稿材料。

为每项记录：

- 规范原文或准确摘要及来源位置/链接；
- 当前稿件对应位置；
- 状态：**已满足 / 未满足 / 待核实 / 需作者补充**；
- 未满足原因和具体下一步。

不能只写“基本符合”。每条明文要求都须有可核对结论。因软件能力、稿件缺项、缺少图表数据、字数超限、目标规则冲突或来源不可访问而不能满足时，直接列出具体条款、现状及需要作者提供/决定的内容；必要时先保存可完成部分并另列问题清单。收到作者补充后再进行二次修改和复核。

不得为了满足格式而编造研究数据、摘要结论、图表内容、作者信息或实验方法。若无法通过合理排版/编辑解决，说明限制并请求真实材料或作者选择。

## 交付样式统计结果

选择“是”时，交付简明结果：样本表和来源、每项统计口径及结果、观察到的规律、哪些属于官方硬性要求、据此拟采用的样式、样本限制。避免把有限样本中的倾向表述成所有文章必须遵守的规则。

无论选择“是”还是“否”，交付期刊/学校正式要求的逐项符合性清单，并将未满足、待核实和需作者补充项单独告知用户。


## 中文期刊引言模式观察
当用户选择学习样文、指定“较好的论文”或提供目标期刊 PDF 时，为中文引言单独记录观察结果。优先选择用户认可的代表作，并补充近期同类型/相近主题论文；样本量有限时说明限制，不把单篇结构当作期刊硬性要求。

| 观察项 | 记录内容 |
|---|---|
| 背景铺垫 | 研究对象的现状、应用场景或现实问题如何切入；是否使用政策/规划、引用多少、放在何处 |
| 研究进展 | 按主题、方法、对象或时间如何分组；作者导向与结论导向如何搭配；中英文文献如何组合 |
| 研究不足/空白 | 如何从已有工作边界、方法局限、样本/情境差异或未解决问题推出；哪些判断有证据支持 |
| 必要性与研究定位 | 如何承接空白，交代研究目的、必要性、问题、方法或贡献 |
| 段落组合 | 要素次序、合并方式、篇幅比例和段间过渡；记录不同样文的可选结构 |

形成可随样文更新的结构建议，不固定套模板。例如“现实/政策背景 → 按主题梳理研究进展 → 有证据支持的局限 → 本文目的”；也可合并背景与研究进展，或从具体技术问题切入。政策仅在与研究问题直接相关时有限采用，优先引用正式原文并核对有效时间。

模仿限于宏观结构、论证顺序、段落功能、研究进展分类和过渡方式；不得复制样文句子、只换同义词或移植其独有论证。样文中的文献只有在与本稿论点直接相关且原文确实支持时才作为引用来源。分别记录样文惯例、拟采用建议和期刊官方要求。


## 表格案例对照与可选统计

上文“否：不做样文统计”仅指不进行多篇样文的量化统计和写作规律分析；它不取消基本表格案例对照。有表格的期刊稿必须查看目标期刊至少一篇同类型已发表论文的实际表格，或用户提供的案例文件，记录题名、来源与表格页码/编号，核对线条、表头、单位、题注、表注和底纹。正式规范优先，规范未详述的格式按案例直接设置。案例不可获得时向作者索要，临时结果标为待核对。


## 最终交付的案例 PDF 对照（强制）

案例学习阶段不是终验。正式规范和 Word 属性检查通过、全部返工完成后，必须导出最终 PDF，与记录在案的同刊案例 PDF 并排或逐页比对。至少覆盖题名/中英文摘要、版心与分栏、层级标题、图表位置/中英文题注/三线表、文内引文、参考文献版式、页眉页脚及跨页分页。记录案例文件、页码、差异、官方规则是否覆盖该项及本稿修正结果；规则优先于案例，案例用于规范未说明处。不可访问案例 PDF 或未能生成最终 PDF 时，案例验收不得报通过。
