# 医学论文演示内容说明

本文档为论文格式一键排版 Skill 的展示样稿。主题为社区高血压随访提醒，研究流程、样本、基线特征和随访完成率均为虚构的排版示例数据；不是真实研究，不代表任何临床疗效，也不应作为医疗建议或学术证据。

引用仅用于演示文内上标编号与文末参考文献对应关系。真实投稿必须以目标期刊规范、真实研究材料和核验后的来源重新排版。

文档内创建的新 Word 段落样式：

- `论文题名`：论文标题
- `作者信息`：作者及单位
- `摘要标题`、`摘要正文`、`关键词`
- `一级标题`、`二级标题`、`论文正文`
- `图题`、`表题`、`表格表头`、`表格正文`
- `参考文献标题`、`参考文献条目`

图表编号和正文指代使用 Word SEQ/REF 域与书签实现；表格边框为样稿中的局部设置，不是独立的 Word Table Style。
